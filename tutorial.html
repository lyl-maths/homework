🚀 步驟 3：Google Apps Script 部署詳細指引

  1. 開啟複製好的 Google Sheet 試算表。
  2. 點擊上方選單列的 「擴充功能」 ➔ 「Apps Script」。
  3. 將系統提供最新的後端 JavaScript 程式碼完整貼入 Code.gs 檔案中並儲存。
  4. 點擊右上角藍色的 「部署」 ➔ 「新增部署」。
  5. 齒輪圖示選擇 「網頁應用程式」：
    • 執行身份：「我」
    • 誰有存取權限：「任何人」 (Anyone) (極為重要！)
  6. 點擊「部署」並授權存取，將複製到的 Web App URL 貼回上方的設定箱點擊儲存即可！
